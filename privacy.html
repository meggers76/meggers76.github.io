Privacy Policy

Last updated: 3 November 2026

Who this applies to

This policy covers Personal Automation Tools: private, non-commercial tools that one individual runs on their own devices for personal use. The only person whose account data the tools access is the owner who authorises them.

What data the tools access

The tools only access data from online accounts (for example Google, Microsoft or media services) after the account owner has explicitly granted permission through the provider's consent screen. Depending on what was approved, this can include:

  • files and documents,
  • contacts,
  • tasks, calendar entries and email,
  • media library and activity data, such as playlists or liked videos.

The tools never request more than what is shown on the consent screen.

How the data is used

Data is used only to carry out tasks the account owner asks for, such as searching, displaying, summarising or organising their own information. When the owner uses an AI assistant to make such a request, the relevant data may be passed to that assistant only to complete the request. The data is not used for advertising or profiling, and it is not used to develop, improve or train generalised AI or machine-learning models.

Storage

Processing happens on the owner's own devices. Access tokens and any temporary caches are stored locally on those devices. The tools do not run a central server or database, and data is not uploaded anywhere else.

Sharing

Data is not sold, rented or shared with third parties. It is transferred only when the account owner directs it as part of a task they request, as described above, or when required by law.

Google user data

The use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Locally stored tokens and caches are kept until access is revoked or the local files are deleted. Access can be withdrawn at any time in the account provider's settings. For Google, use myaccount.google.com/permissions. Revoking access stops all further access immediately.

Security

Access uses the providers' standard OAuth sign-in over encrypted connections. Credentials are never published or shared.

This website

This is a static page with no cookies, analytics or tracking. It is hosted on GitHub Pages, and GitHub may process technical access data such as IP addresses; see the GitHub Privacy Statement.

Changes

If this policy changes, the date at the top will be updated.

Contact

Questions about this policy can be sent to the support email address shown on this app's Google consent screen.
